# FoxOne

One-line layout, hover-reveal icons, dynamic bookmarks bar, floating Findbar, Gruvbox colors and ready for **Nova**

> Tested with Firefox 159 & 153 ESR on Windows, macOS and Linux (GNOME) with `browser.nova.enabled` = `true`.     

![urlbar](assets/preview_cropped.png)

**[Install](https://firnschnee.github.io/FoxOne/installation.html)** | **[Customise](https://firnschnee.github.io/FoxOne/customisation.html)** | **[See it in action](https://firnschnee.github.io/FoxOne/action.html)**

Over 40 variables for colors, layout and toggles and it also works with [Adaptive Tab Bar Colour](https://addons.mozilla.org/de/firefox/addon/adaptive-tab-bar-colour/).     

Using Thunderbird? Take a look at [BirdOne](https://github.com/Firnschnee/BirdOne).
